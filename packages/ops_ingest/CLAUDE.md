# ops_ingest: working rules

Status: current.

The knowledge ingestion library: parse a file into a `ParsedDocument`, split it into chunks and index units by a
source's ingest settings, map metadata and hold items that miss required metadata, dedupe across sources with
effective-dated versions, and apply a source's include and exclude rules. kb-service runs it; it has no server, storage
or embedding of its own. Package rules and test commands: [../CLAUDE.md](../CLAUDE.md); repo-wide rules:
[../../CLAUDE.md](../../CLAUDE.md#folder-guides).

## What it owns

| Module | What it is |
|---|---|
| `parsers/` | `parse(...)`: PDF and PNG, JPEG and TIFF scans (through `reading`), DOCX, HTML (`clean` removes page furniture), XLSX and CSV, plain text and Markdown; `builder` assembles the reading-order stream |
| `reading/` | `read` and `open_file`: one reading of any file into pages (how each page was read, text, blocks with boxes, words with confidence, form fields, OCR quality), OCR `off`, `auto` (scans and the picture areas of mixed pages) or `always`, image files, a 2,000-page limit, one page at a time for resume; `to_parsed_document` turns a reading into what `split` takes. Every PDF and image is read here, whoever asks |
| `split` | `split`, `Pipeline`, `validate_settings`, `InvalidIngestError`: one function from a parsed document and settings to chunks and index units |
| `strategies/` | `structure`, `fixed`, `parent_child`, `table_rows`, `topic`, `faq`, `context_headers`, `clean`, `summarize` |
| `metadata` | Mapping source fields and static values onto items, and the required-metadata hold |
| `dedupe` | Content digests, duplicates across sources, effective-dated versions |
| `rules` | Source include and exclude rules |
| `models` | `IngestSettings`, `ParsingSettings`, `ParsedDocument`, `SplitResult` |
| `model_client` | `ModelClient`, the one protocol ingestion code reaches a model through (`complete(prompt, *, alias, max_tokens)`) |
| `testing` | `FakeModelClient`, which records every call |
| `text` | Token approximation, sentence and word splitting |

## Contract with callers

- The caller passes a `ModelClient` for strategies that call a model (`faq`, `topic`, `summarize`); this package never
  builds a provider client or reads a key.
- Invalid settings are refused by `validate_settings` (two splitters, `parent_child` with `fixed`, size bounds), never
  silently corrected.
- A reading depends only on the bytes, `ReadingSettings` (OCR mode and language, `settings.key`) and
  `READER_VERSION`, so a caller may store it under those and reuse it. A file that cannot be read at all raises
  `ReadingError` with a `code`; a page that cannot be read is listed with `source="none"` and its reason.
- OCR needs the `ocr` extra and the `tesseract` binary. A scanned page with OCR off is reported, and OCR requested but
  missing fails loudly, so an empty page is never indexed as a short one.

Depends on nothing in the workspace. Depended on by `ops_extract`, agents-service, documents-service and kb-service.

## Run and test

| Task | Command |
|---|---|
| The suite (about 20 s) | `make test PKG=packages/ops_ingest` |
| One file | `make test PKG=packages/ops_ingest T=tests/test_split.py` |
| Lint, format, types | `uv run ruff check packages/ops_ingest`, `uv run ruff format --check packages/ops_ingest`, `uv run pyright packages/ops_ingest` |

OCR tests skip when `tesseract` is not on `PATH` (`tests/conftest.py:17`); install it with `brew install tesseract` or
the distribution's `tesseract-ocr` package. The root workspace installs the `ocr` extra. The fixture files in
`tests/fixtures/` are generated by `tests/fixtures/build_fixtures.py`; regenerate them there rather than editing them.
