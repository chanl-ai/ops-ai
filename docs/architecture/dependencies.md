# Runtime dependencies

Status: current. Generated by `make -C services/agents-service sbom` on 2026-10-11 from
`uv.lock`. Do not edit by hand; change the lock or the notes in `services/agents-service/scripts/sbom.py` and regenerate.

79 packages: 12 direct runtime, 56 transitive runtime, 11 dev only (not in the deployed image).

Chat runs on OpenAI (gpt-5.5) per the owner's ruling of 2026-10-10, so Pydantic AI is installed as `pydantic-ai-slim[openai,anthropic]` with no `logfire`. Restriction note: the `openai` extra brings `tiktoken`, which downloads encoding files from a public blob store the first time it is used. For a deployment with no outbound internet, vendor the encoding file into the image and set TIKTOKEN_CACHE_DIR to it. The LangGraph checkpointer is the workspace's own ops-checkpointer on asyncpg, so no LGPL PostgreSQL driver is installed.
